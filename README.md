# 🛡️ NordShield VPN

A modern cross-platform desktop VPN client built with Electron.js, featuring a sleek dark interface inspired by ProtonVPN and Mullvad.

Supports:
- ⚡ WireGuard Integration
- 🔒 OpenVPN Support
- 🌍 Multi-server Selection
- 🖥️ Cross-platform Desktop Support
- 🎨 Modern Animated UI
- 🔐 Secure Electron Architecture

Built for developers and VPN enthusiasts who want a clean, extensible VPN desktop application.
